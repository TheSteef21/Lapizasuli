Manual de Funciones e-Tax 2.0

Listado detallado de los módulos y opciones disponibles en el sistema de la DGI

1. Consultas

Este menú está destinado a la revisión y verificación de información histórica y actual del contribuyente.

  • Anexos a Declaraciones: Permite visualizar los documentos y anexos que se han adjuntado a las declaraciones de impuestos presentadas anteriormente.
  • Buzón Electrónico: Es la bandeja de entrada donde el contribuyente recibe notificaciones, resoluciones y comunicados oficiales de la DGI.
  • Declaraciones Presentadas: Muestra el historial completo de las declaraciones juradas de impuestos que el contribuyente ha enviado al sistema.
  • Documentos: Permite consultar diversos documentos fiscales y legales emitidos o recibidos por la institución.
  • Trámites pendientes: Muestra el estado de las solicitudes o gestiones que el contribuyente ha iniciado y que aún están en proceso de revisión o aprobación.
  • Pagos: Permite ver el historial de los pagos de impuestos realizados.
  • Consultar Informes: Sección para generar y visualizar reportes específicos sobre el estado tributario.
  • Sociedades Agentes Residentes: Consulta de las sociedades vinculadas a un agente residente.
  • Consultas Planilla Anual F3 / Consulta Planilla Anual F3 v2: Permite verificar la presentación del Formulario 03 (Planilla, Fondo de Jubilación y Pensiones).
  • Consulta Detalle F1091: Sirve para consultar los detalles del formulario de informes de donaciones recibidas.

2. Inmuebles

Gestión de obligaciones, pagos y exoneraciones relacionadas con bienes raíces.

  • Pagos F106 y F107 de Inmuebles: Para realizar el pago de los formularios de transferencia de bienes inmuebles y ganancia de capital.
  • Información General de Fincas: Permite consultar los datos, valores y el estado de las propiedades registradas a nombre del contribuyente.
  • Elaborar formulario de Ganancia de Capital (Form. 107): Genera la declaración del impuesto sobre la ganancia obtenida al vender un inmueble.
  • Elaborar formulario de Transferencia de Inmueble (Form. 106): Genera la declaración para el pago del impuesto del 2% sobre la transferencia de bienes inmuebles.
  • Asignar Correo Propietario: Permite actualizar el correo electrónico vinculado al dueño de la finca para recibir notificaciones.
  • Solicitud de Patrimonio Familiar Tributario o Vivienda Principal: Para solicitar la tarifa preferencial o exoneración del impuesto de inmueble para la residencia principal de la familia.
  • Solicitud Exoneración Inmuebles: Trámite para solicitar exoneraciones generales de impuestos sobre ciertas propiedades.
  • Conciliar Pagos (Imp120/ Imp113) Declaraciones (F106 / F107): Permite vincular y aplicar correctamente los pagos realizados a sus respectivas declaraciones de inmuebles.
  • Solicitud de Exoneración por Primera Compra PFT/VP: Trámite específico para exonerar propiedades que han sido adquiridas por primera vez como vivienda principal.

3. Realizar Pagos

Módulo para la generación de documentos de cobro y registro de pagos.

  • Generar boleta a partir de la Cuenta Corriente: Crea un recibo de pago (boleta) con el saldo exacto que se debe según el estado de cuenta del contribuyente.
  • Generar boleta de pago simple - Contribuyente: Permite crear una boleta de pago manual indicando el tipo de impuesto y el monto a pagar.
  • Generar boleta para arreglo de pago: Emite el recibo correspondiente a las cuotas acordadas en un convenio de pago previo con la DGI.
  • Consulta de Boletas de pago electrónicas: Historial de las boletas que han sido generadas en el sistema.
  • Tablero de Pagos: Resumen visual o dashboard del estado de los pagos realizados y pendientes.
  • Log Pagos Tarjetas de Crédito - Contribuyente: Registro detallado de las transacciones de pago de impuestos que se han efectuado utilizando tarjetas de crédito.

4. Agente Residente

Funciones exclusivas para abogados y firmas que actúan como agentes residentes de sociedades anónimas en Panamá.

  • Sociedades Agentes Residentes: Gestión del listado de sociedades que representa el agente.
  • Actualizar Agente Residente: Para modificar los datos de contacto o registro del agente.
  • Consulta Trámite Agente Residente: Permite verificar el estatus de las solicitudes presentadas por el agente.
  • Consulta Declaración Registros Contables / Consulta Declaración Registros Contables V2: Para verificar las declaraciones anuales que certifican que las sociedades offshore mantienen registros contables.
  • Declaración de Registros Contables de Agentes Residentes V2: Formulario para presentar la declaración obligatoria sobre el mantenimiento de registros contables de las entidades jurídicas.
  • Consultar Documentos Registros Contables 2024 / 2021, 2022, 2023: Archivo histórico para revisar la documentación de registros contables enviada en años anteriores.

5. Regularización Tributaria

Gestiones para acogerse a leyes de amnistía o regularizar situaciones específicas.

  • Solicitud Exoneración de tributo de Tasa Única: Para pedir que se exima a una sociedad del pago de la tasa única anual bajo ciertas condiciones legales.
  • Solicitud de Fiscalización Abreviada: Petición para someterse a una auditoría rápida o proceso abreviado para regularizar deudas.
  • Solicitud de Regularización Agentes de Retención de Renta: Trámite para que los agentes de retención puedan ponerse al día con los impuestos retenidos y no pagados.

6. Factura Electrónica

Administración del Sistema de Facturación Electrónica de Panamá (SFEP).

  • Apoderado para retiro de firma electrónica (FEP): Asignación de una persona autorizada para retirar el certificado de firma electrónica.
  • Solicitud de Autorización para PAC: Petición para facturar a través de un Proveedor Autorizado Calificado (PAC).
  • Afiliación contribuyente - Confirmación PAC: Paso donde el contribuyente confirma qué empresa PAC le brindará el servicio de facturación.
  • Declaración Jurada de Adopción al SFEP: Documento formal donde el contribuyente se compromete a usar el sistema de factura electrónica.
  • Solicitud Excepción de SFEP por Naturaleza o volumen de la actividad: Trámite para solicitar permiso para no usar factura electrónica debido a que el negocio es muy pequeño o su naturaleza lo impide.
  • Declaración Jurada de Excepción de SFEP por No Conectividad: Declaración para aquellos negocios ubicados en áreas sin acceso a internet, lo que les impide facturar electrónicamente.

7. Cuenta Corriente Tributaria

Revisión de los saldos a favor o en contra del contribuyente.

  • Consultar Cuenta Corriente: Muestra el balance de los impuestos (cuánto se debe o si hay saldo a favor).
  • Solicitud de Corrección de Cuenta Corriente: Permite abrir un reclamo si el contribuyente detecta que los saldos o pagos reflejados en su cuenta son incorrectos.
  • Consultar Cuenta Corriente Morosos: Visualización específica de los saldos vencidos que han caído en morosidad.

8. Documentación Jurídica

Trámites de carácter legal ante la institución.

  • Presentar Solicitud de Prescripción: Petición formal para que la DGI elimine el cobro de un impuesto debido a que ha pasado el tiempo máximo que otorga la ley para cobrarlo (prescripción).

9. Contador Público Autorizado

Opciones para los profesionales de la contabilidad.

  • Inscripción y/o Modificación CPA: Para que un Contador Público Autorizado se registre en el sistema o actualice sus datos.
  • Solicitud Registro Firma de Contadores: Para inscribir formalmente a una firma o sociedad de contadores ante la DGI.

10. Compensación y Cesión de Créditos Fiscales

Manejo de saldos a favor del contribuyente.

  • Solicitudes de Compensación: Trámite para usar un saldo a favor en un impuesto (ej. ITBMS) para pagar la deuda de otro impuesto (ej. Renta).
  • Solicitudes de Cesión: Procedimiento para transferir (ceder) un crédito o saldo a favor a otro contribuyente distinto.

11. Declaraciones Juradas y Documentos

Este menú agrupa todo lo relacionado con la presentación de declaraciones, informes y la emisión de certificados fiscales.

  • Certificado de no contribuyente del ITBMS: Genera un documento oficial certificando que la persona o empresa no retiene ni declara el Impuesto de Transferencia de Bienes Corporales Muebles y la Prestación de Servicios (ITBMS).
  • Certificación de tasa única: Emite un comprobante que acredita que la sociedad está al día (paz y salvo) con el pago de la tasa única anual.
  • Certificado de actividades exentas de ITBMS: Documento que valida que las actividades económicas del contribuyente están libres del cobro de este impuesto.
  • Declaraciones Pendientes: Muestra un listado de las obligaciones y formularios de impuestos que aún no han sido presentados.
  • Presentar Declaración Jurada: Es el acceso principal para seleccionar, llenar y enviar cualquier tipo de declaración de impuestos (Renta, ITBMS, Dividendos, etc.).
  • Presentar Informes: Módulo para enviar reportes de cumplimiento exigidos por la DGI (ej. informes de compras, donaciones, retenciones).
  • Solicitud de Prórroga: Permite solicitar legalmente una extensión de tiempo para presentar la declaración jurada de rentas sin recargos inmediatos.
  • Solicitar paz y salvo: Trámite para generar el certificado de paz y salvo institucional, necesario para múltiples gestiones comerciales y legales.
  • Solicitud de Arreglo de Pago: Permite al contribuyente proponer y formalizar un acuerdo de pagos en cuotas para cancelar una deuda tributaria.
  • Registrar Formulario 98: Acceso específico para el registro y gestión de este formulario particular.
  • Adjuntar Requisitos CAIR: Opción para subir los documentos probatorios necesarios cuando se solicita la no aplicación del Cálculo Alternativo del Impuesto sobre la Renta (CAIR).
  • Certificación de Sistemas según Método de Facturación: Para registrar y certificar el software o mecanismo que el contribuyente utilizará para emitir sus comprobantes fiscales.

12. Registro Único de Contribuyentes

Este apartado gestiona todo el perfil, la información base y las autorizaciones del contribuyente ante la DGI.

  • Autorizar a otro Contribuyente: Permite delegar permisos a terceros (como un contador, agente residente o abogado) para que realicen trámites en nombre del titular.
  • Solicitud de Actualización RUC: Para modificar la información general del registro, como direcciones, teléfonos, correos electrónicos o la adición de nuevas actividades económicas.
  • Consulta Contribuyente: Muestra el perfil completo, el estado actual y los datos básicos con los que la entidad está registrada en el sistema.
  • Solicitud de Cancelación o Suspensión: Trámite para dar de baja definitiva o suspender temporalmente el RUC, usualmente por cese de operaciones comerciales.
  • Generar Resolución para Rehabilitación de Sociedad: Proceso para reactivar el estado tributario de una sociedad que previamente había sido suspendida.
  • Preguntas de Seguridad: Sección para configurar o actualizar las preguntas secretas necesarias para recuperar el acceso o la contraseña del sistema.
  • Actualización RUC - Tipo Facturación: Permite declarar o cambiar el método autorizado que utiliza el negocio para facturar (equipos fiscales, factura electrónica, etc.).
  • Vinculación del Número Patronal - RUC: Abre un formulario para asociar el Número Patronal (otorgado por la Caja de Seguro Social) al RUC del contribuyente independiente o sociedad comercial, unificando sus datos.
  • Desvinculación del Número Patronal - RUC: El proceso inverso para eliminar la asociación entre un número patronal y el registro tributario actual.
